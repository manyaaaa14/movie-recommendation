ABOUT THIS PROJECT

Movie discovery,
made explainable.

A student project using a real public movie dataset and transparent content-based recommendations.

Project Title
Movie Recommendation System Using Machine Learning
Project Type
Full-stack academic project
Programme
AI for Youth Program
Semester
3rd Semester
Technologies
HTML, CSS, JavaScript, Flask, Pandas, NumPy, scikit-learn
Dataset
MovieLens Latest Small — movies, ratings, and tags from GroupLens.
Recommendation Method
Content-based TF-IDF feature vectors ranked using cosine similarity.
Approach distinction
This system uses content-based similarity. It is not classification, regression, or clustering.
ⓘ Ratings, counts, genres, tags, and recommendations are read or calculated from the locally downloaded MovieLens dataset. Watchlists stay in this browser.
